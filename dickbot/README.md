# DeckGrowerBot

Свой бот-гровер для Telegram-чата, копия механики [@DickGrowerBot](https://github.com/kozalosev/DickGrowerBot)
(MIT + Commons Clause: можно использовать и менять, нельзя продавать). Python + aiogram 3, база SQLite.

## Что умеет

| Команда | Что делает |
|---|---|
| `/grow` | вырасти пиписю раз в сутки: от −5 до +10 см (первые 7 дней только в плюс), сброс в 00:00 UTC (03:00 МСК) |
| `/top` | топ чата, [+] = ещё не растил сегодня, [~] = не растил больше 7 дней |
| `/dod` | Писюн Дня: +1…5 см случайному активному игроку, кроме топ-10% |
| `/pvp <см>` | вызов со ставкой и кнопкой «Атаковать!», шансы 50/50 |
| `/stats` | длина, место, серия дней, статистика боёв |
| `/loan` | кредит, если ушёл в минус: длина обнуляется, 10% каждого прироста идёт на погашение |
| инлайн `@бот` / `@бот 10` | то же самое без команд, как в оригинале |

Перки как в оригинале: «день за днём» (+1 см на 2, 4, 8, 16, 32 дне подряд), «глубокая нора»
(+1% от глубины, если в минусе), «микрозаймер» (выплата кредита).

## Импорт топа из старого бота

В `seed.json` (пример: `seed.example.json`) лежит топ, переписанный со скринов. Команда `/seed` от владельца
загружает его в чат, и владелец оказывается первым. Когда человек из топа впервые нажимает любую команду,
бот узнаёт его по имени и отдаёт ему его сантиметры. Если имя не совпало (поменял ник, сложные символы),
владелец отвечает на сообщение этого человека командой `/link <место в топе>`.

## Запуск

```
pip install -r requirements.txt
BOT_TOKEN=... python bot.py
```

Настройки — в переменных окружения или в файле `.env` рядом с `bot.py` (см. `.env.example`).
Тесты: `python -m pytest tests`.
